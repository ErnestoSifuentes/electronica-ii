# Electrónica II

**Apuntes de Electrónica II**  
Ernesto Sifuentes de la Hoya  
Universidad Autónoma de Ciudad Juárez · Ingeniería Eléctrica

Libro académico en Quarto organizado en **16 semanas**. Incluye el contenido
teórico, actividades, prácticas, ejercicios, simulaciones, materiales ampliados,
ligas a videos y Tutor IA. El contenido completo del repositorio se destina a
los estudiantes.

## Organización del repositorio

- `semanas/`, `index.qmd`, `tutor-ia.qmd`, `_quarto.yml`: fuentes editables.
- `_book/`: páginas HTML compiladas del libro.
- `recursos/`: figuras, presentaciones, guías, simulaciones y apuntes.
- `fuentes-docente/`: documentos originales y recursos complementarios.
- `.github/workflows/`: publicación automática en GitHub Pages.
- `scripts/`: construcción y verificación del sitio.
